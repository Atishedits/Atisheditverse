# EditVerse Portfolio Website

A responsive video-editor portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and booking form
- `style.css` — dark + purple responsive design
- `script.js` — mobile menu and small interactions

## Before publishing
1. Open `index.html`.
2. Replace every `YOUR_EMAIL@example.com` with the email address where you want booking enquiries.
3. Replace the `https://instagram.com/` link with your Instagram profile URL.
4. Replace the demo portfolio cards with links or embeds of your real editing samples. Do not present demo visuals as client work.
5. Save all files.

## Booking form setup
The form uses FormSubmit (`https://formsubmit.co`). On the first real submission, FormSubmit sends an activation email to the address in the form action. Open that email and activate the form. After activation, new enquiries are sent to that inbox. Test it yourself before sharing the website.

For production, you can later switch to Formspree or a custom backend. Never put email passwords or secret API keys in frontend files.

## Publish free with GitHub Pages
1. Sign in at https://github.com
2. Click **New repository**.
3. Name it `editverse-portfolio` and choose **Public**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. GitHub Pages will show your live website URL in the Pages section.

## Important
The portfolio thumbnails are designed demo visuals, not real video samples. Add your own work before using this as a client-facing portfolio.
